# 贪吃蛇 OJ 自动解题版（snake-oj）

用 C 语言实现的贪吃蛇自动解题程序，通过**标准输入输出**与评测机（OJ）交互，自身完成路径规划与走位决策。

## 编译

纯标准库实现，无任何第三方依赖：

```bash
gcc snake高分.c -o snake
```

（Windows 下可用 `cl snake高分.c` 或任意 C 编译器，需支持 C99。）

## 运行与交互协议

程序是**交互式**的：从 `stdin` 读评测机数据，向 `stdout` 输出每一步决策。

1. 先读 **20 行**地图，每行 21 个字符（含结尾 `\0`），字符含义：
   - `H` 蛇头、`B` 蛇身、`F` 食物、`#` 墙壁/边界、`.` 空地
2. 再读一个整数 `f_iv`：生长间隔（每 `f_iv` 步蛇身强制增长一节）
3. 进入主循环，每轮：
   - 输出一行 `方向\n`（`W/A/S/D` 之一）和一行 `当前分数\n`
   - 读入下一食物坐标 `n_fr n_fc`；若 `n_fr == 100` 表示对局结束，程序打印最终地图与分数后退出

本地自测时，可把符合上述格式的输入通过管道喂给程序：

```bash
./snake < test_input.txt
```

## 算法思路

核心在 `get_move()`，三级决策优先级：

1. **能吃就吃**：BFS 找到蛇头到食物的最短路径；落子前用 `eval_space()` 评估「吃完后能否回到尾部 / 仍有足够活动空间」，空间充足才走这一步，避免把自己困死。
2. **追尾巴**：当无法直接安全吃食物时，选择「走一步后蛇头离蛇尾曼哈顿距离最大」的方向，拖延等待空间打开（Hamiltonian 思想的简化）。
3. **走向最空处**：兜底策略，朝周围可达空间最大的方向走，尽量不撞墙 / 不咬自己。

辅助结构：`can_go()` 判断格子可否走（含「尾巴会让开」的 `skip_tail` 处理），`find_path()` 是 BFS + 前驱回溯，`eval_space()` 是带剪枝的 Flood Fill 空间估算。
