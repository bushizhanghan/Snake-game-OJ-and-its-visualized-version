# ============================================================
# 贪吃蛇可视化游戏 — 环境依赖清单
# ============================================================
# 使用方法：按顺序安装以下依赖，然后打开 .sln 文件编译运行
# ============================================================

# [必装] 操作系统
# -----------------
# Windows 7 SP1 / Windows 10 / Windows 11
# EasyX 仅支持 Windows 平台，不支持 macOS 和 Linux

# [必装] Visual Studio 2022
# --------------------------
# 下载地址：https://visualstudio.microsoft.com/
# 版本：Community（免费）/ Professional / Enterprise 均可
# 安装时必须勾选工作负载：使用 C++ 的桌面开发
# 附带组件（自动包含）：
#   - MSVC v143 - VS 2022 C++ x64/x86 生成工具
#   - Windows 10/11 SDK
#   - C++ CMake 工具（可选）

# [必装] EasyX 图形库
# --------------------
# 下载地址：https://easyx.cn/download
# 最低版本：2024 年版
# 安装方式：
#   1. 下载 EasyX 安装包（exe 格式）
#   2. 双击运行，自动检测已安装的 Visual Studio 版本
#   3. 勾选你的 VS2022，点击"安装"即可
#   4. 无需手动配置 include 或 lib 路径
# 说明：EasyX 是基于 Windows GDI 的 C++ 图形库，
#       提供 initgraph/loadimage/putimage 等绘图函数

# [必装] 图片资源文件
# --------------------
# 以下文件必须与 .exe 在同一目录下：
#   head_new.png    - 蛇头贴图（30x30 像素）
#   body.png        - 蛇身贴图（30x30 像素）
#   food.png        - 食物贴图（30x30 像素）
#   wall.png        - 墙壁贴图（30x30 像素）
#   bg.png          - 背景贴图（30x30 像素）
# 这些文件已包含在项目中，无需额外下载

# [自动生成] record.dat
# ----------------------
# 最高分存档文件，首次运行时自动生成
# 以二进制格式存储，经过 XOR 加密

# ============================================================
# 编译配置
# ============================================================
# 解决方案平台：x64（不是 x86）
# 编译器：MSVC v143
# C++ 标准：C++14 或更高
# 字符集：Unicode（项目默认配置）
# 子系统：Windows（不是控制台，但保留了控制台窗口）
